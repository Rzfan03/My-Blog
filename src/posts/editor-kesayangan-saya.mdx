Helix adalah code editor berbasis berbasis terminal mirip seperti vim, nvim dan kakoune. Kenapa saya mengunakan helix? karena saya sudah lelah dengan code editor yang lambat dan memakan resource banyak seperti vscode, dll. jadi sebagai alternatif saya memilih helix untuk code editor karena ringan tidak memakan banyak resource dan open source
